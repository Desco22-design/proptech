# PropTech — Real Estate Developer Landing

Современный лендинг застройщика недвижимости. Каталог строящихся жилых
комплексов с фильтрами и поиском, промо-карусель, формы заявки и контакты.

Дизайн и структура выполнены в стиле девелоперского сайта (референс: NRG-BI):
точная палитра, типографика Inter, сетка карточек проектов и адаптивная вёрстка.

## Возможности

- **Hero** — промо-карусель (автопрокрутка, стрелки, точки) + карточка «Купить онлайн»
- **Каталог проектов** — рабочие фильтры (локация, тип, цена, комнатность) и поиск в реальном времени
- **12 карточек ЖК** с реальной фотографией, бейджами класса, ценой и характеристиками
- **О компании** — статистика и описание
- **Ценности** — 3 карточки-истории
- **Заявка на звонок** — маска телефона `+998`, валидация
- **Контакты** — карта и отделы продаж
- Адаптивность, доступность, scroll-reveal анимации (с учётом `prefers-reduced-motion`)

## Стек

Чистый статический сайт — **HTML + CSS + JavaScript** без сборки и зависимостей.
Шрифт Inter / Sora подключается через Google Fonts, фотографии — Unsplash.

## Структура

```
Proptech/
├─ index.html            # разметка всех секций
├─ assets/logo.svg       # фавикон-монограмма
├─ css/
│  ├─ tokens.css         # дизайн-токены (цвет, типографика, отступы)
│  ├─ base.css           # сброс и базовая типографика
│  ├─ components.css     # кнопки, бейджи, поля, логотип
│  ├─ header.css         # шапка и навигация
│  ├─ hero.css           # промо-карусель и hero
│  ├─ projects.css       # фильтры и сетка карточек
│  └─ info.css           # о компании, ценности, контакты, футер
└─ js/
   ├─ projects.js        # данные каталога, рендер и фильтрация
   └─ main.js            # карусель, меню, форма, анимации
```

## Запуск

Откройте `index.html` в браузере — никакой установки не требуется.

Локальный сервер (опционально):

```bash
npx serve .
# или
python -m http.server 8000
```
